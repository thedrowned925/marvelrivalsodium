# Karakter Hover Sesleri

Bu klasöre her karakter için kısa bir `.mp3` koyun. Dosya adı karakter slug'ı ile aynı olmalıdır.

Örnekler:
- `groot.mp3`
- `spider-man.mp3`
- `peni-parker.mp3`
- `the-punisher.mp3`
- `capt-america.mp3`
- `dr-strange.mp3`

Davranış: mouse karakter kartına girince ses başlar; mouse karttan çıkınca anında durur ve başa sarar.

Öneri: 2–5 saniye, MP3, 96–160 kbps, mümkünse normalize edilmiş ses seviyesi.
